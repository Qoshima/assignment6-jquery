# Assignment 6 - jQuery

**Student:** Yernur Alimbekov  
**Group:** SE-2524

A simple website with 12 jQuery tasks. **Each task has its own HTML and JavaScript file**. The styling is minimal and shared across pages.

## How to run

1. Unzip the project.
2. Open `index.html` in a browser (or use WebStorm's built-in preview).
3. Choose **Task 0** through **Task 11** from the navigation bar.
4. For Task 0, open your browser's developer console to see `jQuery is ready!`.

An internet connection is needed to load jQuery from the CDN.

## Files

- `index.html` - home page and navigation.
- `task0.html` + `JS/task0.js` - CDN setup and document ready.
- `task1.html` + `JS/task1.js` - ID, class and tag selectors; `.text()`, `.html()`, `.css()`.
- `task2.html` + `JS/task2.js` - `.hide()`, `.show()`, `.toggle()`.
- `task3.html` + `JS/task3.js` - `.fadeIn()`, `.fadeOut()`, `.fadeToggle()`.
- `task4.html` + `JS/task4.js` - `.slideUp()`, `.slideDown()`, `.slideToggle()`.
- `task5.html` + `JS/task5.js` - `.append()`, `.prepend()`, `.remove()`.
- `task6.html` + `JS/task6.js` - changing `src` and `href` with `.attr()`.
- `task7.html` + `JS/task7.js` - live text from `.val()`.
- `task8.html` + `JS/task8.js` - basic `.animate()`.
- `task9.html` + `JS/task9.js` - sequential `.animate()` calls.
- `task10.html` + `JS/task10.js` - combined `.animate()` properties.
- `task11.html` + `JS/task11.js` - mini-project: clickable image gallery.
- `style.css` - shared simple styling.
- `images/` - three small local SVG images.

Only jQuery and plain HTML/CSS are used. No extra frameworks or build tools are needed.
